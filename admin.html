Conectar o painel ao site

O site fica no GitHub. Para o Publicar funcionar, este aparelho precisa de uma chave (só uma vez). Ela fica salva só neste navegador.

  1. Clique: criar chave no GitHub (já vem com nome e validade preenchidos)
  2. Em Repository access, escolha Only select repositories → adega-brasil
  3. Em Permissions → Contents, escolha Read and write
  4. Clique em Generate token, copie a chave e cole aqui embaixo
