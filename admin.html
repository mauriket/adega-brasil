🔑 Conexão para publicar

O site fica no GitHub. Para o botão Publicar funcionar, este aparelho precisa de uma chave do GitHub (só uma vez). A chave fica salva só neste navegador.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Token name: painel adega · Expiration: escolha "No expiration" ou 1 ano
  3. Repository access: "Only select repositories" → escolha adega-brasil
  4. Permissions → Repository permissions → Contents: "Read and write"
  5. Clique em Generate token, copie e cole abaixo
