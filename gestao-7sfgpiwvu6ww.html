Conectar o painel ao site

O site fica hospedado no GitHub. Para que o botão Publicar funcione, este aparelho precisa de uma chave de acesso (configuração única). A chave fica salva apenas neste navegador.

  1. Acesse criar chave no GitHub (nome e validade já vêm preenchidos)
  2. Em Repository access, selecione Only select repositories e escolha adega-brasil
  3. Em Permissions, defina Contents como Read and write
  4. Clique em Generate token, copie a chave e cole abaixo

Avançado

Contas de acesso

Cada pessoa entra no painel com o próprio e-mail e senha. A chave do GitHub fica guardada criptografada com a senha de cada conta. Use senhas fortes (10+ caracteres, com letras e números) e não as compartilhe.

Backup

Baixe uma cópia de todos os produtos, promoções e configurações. Para restaurar, importe o arquivo e depois clique em Publicar.

Descartar volta o painel para a versão publicada, apagando as alterações não publicadas deste aparelho.

Histórico de publicações
